# 2.8-ESP32-CYD-dual-USB-Photo-Display
CYD Photo Frame: project summary A firmware for the ESP32-2432S028 "Cheap Yellow Display" (dual USB, ST7789) that turns the board into an SD-card photo frame. You can load images by SD card or over WiFi, and install the firmware from a web page.

Online webflasher: https://espterminator.com/
